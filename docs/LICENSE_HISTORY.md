# Histórico de licenciamento do Solo-MCP

## Ramo principal, a partir da alteração da licença

O arquivo `LICENSE` do projeto foi substituído pela
**PolyForm Noncommercial License 1.0.0**. O código disponibilizado sob
esses termos pode ser usado, modificado e redistribuído apenas dentro
das finalidades permitidas pela licença, preservando as notificações
obrigatórias. A exploração comercial não é concedida.

Esta licença **não** é compatível com a definição OSI de open source,
pois ela não permite o uso comercial irrestrito; descrevemos o repositório
como software com **código-fonte disponível para fins não comerciais**.

O aviso `Required Notice: Copyright (c) 2026 Solo-MCP contributors`
deve acompanhar cópias distribuídas sob estes termos.

## Revisões publicadas antes da alteração

O repositório continha anteriormente a **MIT License**. Ela concedia
direitos que incluem uso comercial, distribuição e sublicenciamento
das versões disponibilizadas sob MIT.

**A alteração atual não revoga retroativamente concessões anteriores.**
Pessoas que obtiveram legitimamente essas versões podem conservar direitos
adquiridos sob a MIT. O histórico Git mantém as revisões e a licença antiga.

A troca de licença para código já publicado deve respeitar os direitos
autorais de todos os contribuidores. Se houver código de terceiros,
o licenciante só pode aplicar condições novas às partes sobre as quais
tenha direitos suficientes. Este documento não altera direitos de terceiros.

Consulte um profissional de direito autoral para uma decisão jurídica
específica sobre contribuições, relicenciamento e aplicação dos termos
ao histórico do projeto.
